## Beschreibung

EdTech bietet Programme an, die sich grösstenteils auf Bildung auf dem gymnasialen Niveau fokussiert und zum Teil auch als Erleichterung des Schulalltags von Schülerinnen und Schülern dient.

---

## Inhalte

|  | Beschreibung |
|---|---|
| **BKS Assistant v.3.2** | Schnellzugriff für die BKS Chur |
| **HexaLengua (Rosshan's Version)** | Multilinguales Nachschlagewerk und Vokabeltrainer |
| **vibecoder v.1.0** | Kleinprojekte, die durch vibecoding entstanden. |
| **Tutor Asssitant v.2.1** | Verwaltungssoftware für Nachhilfelehrpersonen |
| **Onion Studio v.1.0** | Frame-by-Frame Animationssoftware |
