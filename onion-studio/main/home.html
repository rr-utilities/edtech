Über Onion Studio

Im Onion Studio können Zeichentrickfilme Frame für Frame von Hand gezeichnet und produziert werden. Dieses Program dient aber nicht als hochprofessionelles Produktionstools, sondern eher für kleinere Hobby-Projekte. Dieses Studio ist zumdem komplett kostenfrei und open source (d.h. auf GitHub verfügbar) und beinhaltet ebenfalls das selbstentwickelte System, das sogenannte Konzept 1, bei der Daten so gespeichert werden, dass hier keine Clouds oder Accounts gebraucht werden.
